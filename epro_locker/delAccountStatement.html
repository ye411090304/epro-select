Account deletion guidelines

Application name: ePro Smart

Developer name: Shenzhen Epro Software Co.Ltd

In order to better realize users' personal privacy rights, we provide a "delete account" function in the application. Users can find the entrance to cancel personal information (account) through the following path:

App -> Homepage -> My -> Account management -> Delete Account

When a user deletes personal information (account), we will delete the information submitted by the user through the application, as well as device information and log file information, including the following categories:

1. Registered account information: including email address, phone number, username and login credentials, as well as nickname, country code, language preference or time zone information in the account.

2. User feedback: include email address, mobile phone number.

3. Mobile device information: includes mobile device information, including mobile device model, login IP address, wireless connection information, operating system type and version, application version number, push notification identifier, log file and mobile network information, software version number, Information about mobile apps and other software, as well as app install lists for apps.

4. Basic information of smart devices: name, device ID, online status, activation time, firmware version and upgrade information of the smart device.

5. Information collected during the process of connecting smart devices: Based on the type of smart device the user needs to connect to, whether it is connected through Wi-Fi, connected through Wi-Fi after establishing a local connection through Bluetooth, connected through Bluetooth or through Zig-bee method, we All will collect the Mac address of the smart device.

When a user deletes personal information (account), we will retain the following information to ensure that it cannot be associated with the user's identity, and perform automatic deletion regularly according to the information retention period (customers are asked to determine their own retention period), which specifically include the following categories:

1. Contents in user feedback, if there are pictures or videos actively submitted by users, or problem logs submitted, we retain them in order to further analyze the problem and find the best solution. When the user applies for deletion of personal information (account), we will It will be retained according to the 3-year retention period (please confirm by the customer);

2. Log information: System and exception logs will be uploaded for analysis, including IP address, usage habits, operating system version, date or time of access, so that we can accurately identify problems and help users solve problems during service use. If the problem arises, it will be deleted after 7 days (please confirm by the customer);

3. Information reported by smart devices: For example, videos will be deleted when the user's purchase time expires (if any, please confirm by yourself).
